📌 Portfolio Entry #1 – Clinical Project
🧬 Project: Predicting Diabetes Using Logistic Regression in R

Overview:
Built a predictive model using logistic regression to estimate the likelihood of diabetes in patients based on health and lifestyle features. The goal was to demonstrate how statistical modeling can support early diagnosis and intervention in chronic disease management.

Tools & Methods:

    R: Logistic regression, data preprocessing, model evaluation

    Data: Public dataset with clinical and demographic variables (e.g., age, BMI, glucose levels, physical activity)

    Metrics: Accuracy, precision, recall, ROC-AUC

Key Achievements:

    Cleaned and processed over 1,000 patient records with missing data handling and feature selection

    Achieved a model accuracy of 86% and ROC-AUC of 0.89

    Interpreted odds ratios for key predictors, showing strong correlation between BMI and diabetes risk

    Visualized risk distribution and model performance to support clinical decision-making
